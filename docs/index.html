Ubah video jadi not angka

Tempel link YouTube, pilih file, atau rekam lewat mikrofon — dapatkan melodi angka untuk tangan kanan dan chord untuk tangan kiri & gitar. Transpose ke nada dasar mana pun, lengkap dengan saran capo. Semua jalan di browser.

Rekam audio dari video

  1. Klik Mulai rekam.
  2. Di jendela berbagi, pilih tab ini dan pastikan "Bagikan audio tab" aktif.

    NotAngka — transkripsi otomatis untuk latihan pribadi. Hasil perlu dicek ulang. Kode sumber di GitHub

    Cara pakai NotAngka

    Semua berjalan di browser — tidak perlu install apa pun.

    1. Link YouTube (Chrome/Edge di laptop): tempel link → Proses → Mulai rekam → pilih tab ini & aktifkan "Bagikan audio tab". Audio direkam selama video diputar, lalu dianalisis otomatis.
    2. File: pilih file audio/video (mp3, m4a, wav, mp4…) → Proses. Paling cepat & akurat.
    3. Mikrofon (cocok di HP): putar lagunya dari speaker lain, klik Mikrofon → rekam → selesai.

    Pisah vokal & lirik otomatis berjalan di browser memakai GPU (WebGPU, mis. Chrome di Mac M1). Model AI diunduh sekali (±180 MB) lalu tersimpan di browser.

    Opsional — aplikasi Mac: unduh link YouTube langsung tanpa perlu merekam tab:

    cd ~ && (git clone https://github.com/laucan8/notangka.git || true) && bash ~/notangka/mac/install.sh

    Jika aplikasi Mac berjalan, halaman ini otomatis memakainya (status kanan atas: Terhubung).

    Pengaturan server

    Alamat server NotAngka lokal. Default: http://127.0.0.1:8765.
