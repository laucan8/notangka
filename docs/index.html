    Jalankan NotAngka di Mac

    Pemrosesan YouTube berjalan di komputer kamu. Sekali setup, lalu cukup jalankan server setiap mau dipakai.

    1. Unduh kode & setup (sekali saja, butuh Homebrew):
      git clone https://github.com/laucan8/notangka.git && cd notangka && bash setup_mac.sh --full
    2. Jalankan server (setiap kali mau pakai):
      cd notangka && ./run.sh
    3. Kembali ke halaman ini — status di kanan atas berubah jadi Terhubung. Di Chrome, izinkan akses jaringan lokal jika diminta. Di Safari, buka http://127.0.0.1:8765 (tampilan yang sama).

    Pengaturan server

    Alamat server NotAngka lokal. Default: http://127.0.0.1:8765.
